# grid-game-bot

VK-бот (Bots Long Poll API) на Java 17 + Gradle. Игровая сессия для каждого пользователя в отдельном потоке.

## Развёртывание на Amvera Cloud

Поддерживает Java/Gradle, автоматический деплой через Git или загрузку файлов через интерфейс.

### 1. Подготовка репозитория

В корне проекта уже созданы:

- **`amvera.yml`** — конфигурация сборки и запуска для Amvera
- **`build.gradle`** — сборка Gradle с задачей `vkJar` (толстый JAR бота)
- **`.env.example`** — шаблон переменных окружения (не коммитьте реальные значения)

### 2. Создание приложения в Amvera

1. Зарегистрируйтесь на [amvera.ru](https://amvera.ru).
2. Создайте новое приложение.
3. Выберите способ загрузки кода:
   - **Через Git** — подключите свой GitHub/GitLab/Bitbucket репозиторий (рекомендуется для удобных обновлений через `git push`).
   - **Через интерфейс** — загрузите файлы проекта напрямую в веб-интерфейсе Amvera.

### 3. Конфигурация `amvera.yml`

Убедитесь, что в корне проекта есть файл `amvera.yml`:

```yaml
meta:
  environment: jvm
  toolchain:
    name: gradle
    version: 17

build:
  artifacts:
    "build/libs/*.jar": /

run:
  jarName: app-1.0.0-vk.jar
  persistenceMount: /data
  containerPort: 8080
```

### 4. Переменные окружения

В разделе **«Переменные»** веб-интерфейса Amvera добавьте:

| Название | Значение |
|----------|----------|
| `VK_TOKEN` | Токен сообщества VK (настройки группы → API) |
| `VK_GROUP_ID` | ID сообщества VK | Обычная переменная |

После добавления переменных **нажмите «Перезапустить контейнеры»**

### 5. Запуск

1. Нажмите **«Пересобрать»** — Amvera выполнит `gradle build`, соберёт `vkJar` и развернёт приложение.
2. После успешной сборки нажмите **«Включить»** (если приложение не запустилось автоматически).
3. Проверьте вкладку **«Лог приложения»** — должно быть видно:
   ```
   Бот запущен. Сообщество: <ваш_group_id>
   ```

### 6. Проверка работы

Напишите боту в VK — он должен отвечать на сообщения.
